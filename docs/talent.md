# 菌护禾 · 招募岗位与人才画像

> 依据：菌护禾方案（3 页 PDF，2026-10）＋ 公开资料核实（见 §5）。**具体招募事项（岗位方向、培养安排、是否录用）由团队根据面试与实际需要决定。**

## 1. 项目一句话与阶段

**菌护禾**：在菌最容易死、作物最关键的 **0–30 天定殖窗口**，用 150 元级微灌（ESP32 + 电容式水分 + DS18B20 + 小水泵）在"水分偏低且温度适宜"时自动小水量补墒，把根际活菌托在功能阈值以上；窗口结束系统退出。

**当前阶段**：方案验证 + 样机迭代；第一阶段以**第 7/15 天根际活菌数（CFU/g 鲜土）**为硬指标，产量与品质放到第二阶段。

## 3. 人才画像（不分岗位的共性）

**要的三件事**（与方案的风险点一一对应）：

1. **能下田**：方案最大的不确定性在田间（活菌数→产量、传感器漂移、花芽分化期补水冲突），只在实验室里想是不够的。
2. **能动手**：样机、传感器标定、泵与水量、光伏供电都要真的装到棚里跑 30 天。
3. **能跨专业协作**：微生物、农艺、硬件、数据、渠道五套语言，必须有人能把它们翻译成同一张试验方案。

**性格倾向**（网站四维里的协作与韧性）：
- 面对"数据不显著"不急着换方向，先查方法误差；
- 面对农户要拆设备，先解决现场问题再解释；
- 面对跨专业冲突，用证据定规则，而不是靠职位或人情。

**能力倾向**（四维里的分析与执行）：
- 分析判断：能拆解"为什么菌会死/为什么不显著/为什么农户不付费"；
- 执行推进：能把 30 天窗口的试验按天排出来并盯到位。

## 6. 建议的招募流程

1. **初筛**：简历 + 作品（样机/试验/代码/渠道资源任一）。
2. **在线评估**（本网站）：4 题情境 + 自我介绍 + 4 个 AI 追问 → 综合分 + 人岗匹配。
3. **真人面试**（30–45 分钟）：按报告的"面试官可追问方向"问 3 个问题，重点验证一手经验。
4. **试用任务**（1–2 周，带薪/项目制）：
   - 微生物：完成一次活菌计数并给出误差分析；
   - 农艺：写一份 3 处理 × 3 重复的盆栽方案；
   - 硬件：把样机连续跑 7 天并提交日志；
   - 数据：用给定数据做一次 ANOVA + 多重比较；
   - BD：访谈 2 家合作社并给出付费意愿结论；
   - 运营：拆解一次登记/申报路径与时间表。
5. **双向选择**：岗位、投入方式（全职/兼职/实习）、待遇与股权按团队规则面谈。
